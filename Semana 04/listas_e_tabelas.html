Glossário Acadêmico

Algoritmo
Conjunto finito de instruções ou regras lógicas bem definidas, estruturadas para resolver um problema ou executar uma tarefa específica.
API (Application Programming Interface)
Interface que define protocolos e padrões de comunicação, permitindo que softwares e sistemas distintos troquem dados e interajam de forma padronizada.
Recursão
Método de programação no qual uma função invoca a si mesma repetidamente até atingir uma condição de parada pré-determinada (caso base).
